## What this site collects

This site is hosted on GitHub Pages. GitHub Pages records standard web server access logs (IP address, browser type, pages requested, timestamps). I do not control or access these logs directly — they are held by GitHub under [GitHub's privacy policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

### Cloudflare Web Analytics

This site uses [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) to understand which pages are useful and where visitors come from. It collects aggregate page-view counts, referrer information, and general device and browser data.

Cloudflare Web Analytics does not use cookies and does not track individuals across sites. No IP addresses are stored. The data is held by Cloudflare under [Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/).
